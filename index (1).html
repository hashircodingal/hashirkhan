01 — THE BASICS

What is HTML?

HTML uses elements and tags to describe the structure and meaning of content. Browsers read HTML and display it as a webpage.

◇

Markup language

HTML is not a programming language. It marks up content with tags so browsers understand it.

▣

Document structure

HTML creates headings, paragraphs, links, images, lists, tables, forms, and more.

◎

Works with CSS & JS

HTML provides structure, CSS adds style, and JavaScript adds behavior and interaction.

HTML document anatomy

A standard HTML file has a document type declaration, a root <html> element, metadata in <head>, and visible content in <body>.

<!DOCTYPE html>
<html>
  <head>
    <title>Page title</title>
  </head>
  <body>
    Visible content goes here
  </body>
</html>

02 — BUILDING BLOCKS

Essential HTML elements

Elements usually have an opening tag, content, and a closing tag.

ElementPurposeExample
<h1> – <h6>Headings<h1>Title</h1>
<p>Paragraph<p>Text</p>
<a>Hyperlink<a href="...">Link</a>
<img>Image<img src="..." alt="...">
<ul> / <ol>Unordered / ordered list<li>Item</li>
<div> / <span>Generic containers<div>Content</div>
Attributes: Attributes provide extra information about an element. For example, href defines a link destination and class identifies an element for CSS styling.

03 — MEANINGFUL MARKUP

Semantic HTML

Semantic elements clearly describe their purpose to browsers, search engines, and assistive technologies.

header
nav
main
article
aside
footer

Common semantic elements

  • <header> Introductory content or navigation
  • <nav> A group of navigation links
  • <main> The page's primary content
  • <section> A thematic content section
  • <article> Independent, reusable content
  • <footer> Closing information for a page or section

04 — USER INPUT

Forms and media

Forms collect information

<form>
  <label for="email">Email</label>
  <input id="email" type="email">
  <button type="submit">Send</button>
</form>

Images, audio, and video

Use media elements to include rich content. Always provide alternative text for images.

<img><audio><video><iframe>

The alt attribute helps users who cannot see images understand their content.

05 — BEST PRACTICES

Write better HTML

01

Use valid structure

Always include <!DOCTYPE html>, language information, and a viewport meta tag.

02

Choose semantic tags

Prefer meaningful elements over using <div> for everything.

03

Think accessibility

Connect labels to inputs, add image alt text, and use headings in the correct order.

04

Keep it organized

Indent nested elements, use lowercase tags, and close every non-void element.
